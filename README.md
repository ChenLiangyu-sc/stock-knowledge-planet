# Stock Knowledge Planet · 知识星球股票信息整理

把知识星球「信息社」(group id `15522441485522`) 里的券商/机构类信息，整理成一份**可直接交给网页 AI 做进一步推荐诊断**的候选股票清单。

## 工作流

```
知识星球(信息社) ──抓取──> data/raw/*.json(不入库)
                    │
                    ├──词典匹配/券商标签解析──> scripts/extract.py
                    ▼
        docs/zsxq-stock-digest-<date>.md   ←—— 本仓库核心交付物
                    │
                    ▼  push 到 GitHub 后
        网页 AI(如 ChatGPT/Gemini) 按文档中的"诊断清单"收集行情/公告/研报
        做进一步验证与风险提示
```

## 目录

```
├── docs/                     # 整理后的股票信息文档（核心交付物，可入库）
```

## 文档使用方式（给网页 AI 的正确姿势）

打开 `docs/` 下最新的 digest 文档，把它整体贴给网页 AI，并附一句指令，例如：

> 这是知识星球券商信息群里整理出的股票候选清单，请针对文中"待诊断"部分的问题，
> 逐只收集最新行情、公告、业绩与风险信息，给出验证结论与风险提示。

文档里每只候选股都带：
- **星球观点脉络**：群内券商点评的时间线摘录（谁在什么日子说了什么）
- **代表原文**：≤80 字短引用 + 日期（版权礼貌，只留摘要级引用）
- **待诊断问题**：交给网页 AI 的具体验证任务（估值、业绩兑现、催化剂、风险）

## 数据来源与方法

- 来源：知识星球「信息社」（付费社区，仅限个人研究使用，请勿传播原文）
- 抓取：ZsxqCrawler（本地 cookie 已过期时，用 opencli 浏览器会话分页抓取，注意 1059 风控限频，需温和节奏）
- 提取：A 股全名单 + 常见港美股权衡名称词典匹配，`【券商行业】` 标签解析；
  已知局限：简称歧义（同名/一词多义已做黑名单）、主题词误报可能存在，引用前请人工复核
- 信号：全量话题提及频次（近期热度）＋ 精华帖提及（全期质量信号）＋ 推荐类关键词（金股/首推/强 call 等）
